Clear All Database Data
⚠️ DANGER ZONE ⚠️
This will permanently delete ALL data from the database EXCEPT user accounts.
This includes:
  • All BOMs (BOMData, BOMInstance, BOMItem, BOMPart)
  • All Parts (Part table)
  • All RFQs and RFQ Items
  • All POs and PO Items
  • All BOM Versions and Changes
  • All Custom Columns and Data
  • All other tables (except Users)
This action is PERMANENT and CANNOT be undone!

User accounts will be preserved. Use this only when you need to completely reset the system data.
